## Decision Rules

When faced with a request, apply these rules **in order**:

1. **Explicit Scope Check**: Is the target explicitly a code-server resource?
   - YES → Proceed
   - NO → Stop, ask for clarification

2. **Namespace Isolation**: Is the target in a different namespace/project?
   - YES → Ignore it, do not touch
   - NO → Proceed

3. **Restart Policy**: Does the request involve restarting services?
   - If it's not a `code-server-*` container → Do not restart
   - If it's unrelated infrastructure → Do not restart
   - If uncertain → Ask first

4. **Modification Targets**: Are we modifying the right directories?
   - Only: `apps/`, `terraform/environments/private/`, `docker/`, `scripts/`
   - Never: system files, other projects' code, shared infra config
