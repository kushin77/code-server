# Ephemeral Session Evidence Pack Runbook

## Purpose
Provide an operator and auditor workflow for retrieving, validating, and exporting teardown evidence packs generated by the ephemeral workspace lifecycle manager.

## Scope
This runbook covers evidence packs generated at teardown for both successful and failed session lifecycles.

## Evidence Schema
- Schema version: `ephemeral-evidence-v1`
- Primary key: `sessionId`
- Manifest fields:
  - `checksums.eventLog`
  - `checksums.testOutcomes`
  - `checksums.fingerprints`
  - `checksums.deletionProof`
  - `checksums.manifest`
  - `manifestSignature`
- Retention policy: 30 days (configurable via `evidenceRetentionDays`)

## Retrieval Workflow
Use lifecycle manager APIs by session ID:

1. Retrieve full evidence pack:
   - `getEvidencePackBySessionId(sessionId)`
2. Retrieve export payload for issue comments/compliance reports:
   - `exportEvidenceBySessionId(sessionId)`
3. Verify manifest integrity:
   - `verifyEvidenceManifest(sessionId)`

## Retention Workflow
Retention cleanup is automatic during monitoring loops and can be forced manually:

- Automatic: `startMonitoring()` calls `enforceEvidenceRetention()` periodically.
- Manual: `enforceEvidenceRetention(nowSeconds)` for backfill or maintenance windows.

## Sample Audit Walkthrough
Session: `session-gc`

1. Perform teardown (`hardDeleteWorkspace`) and confirm evidence exists:
   - Expected: `teardownOutcome=success`
2. Verify evidence:
   - Expected: `verifyEvidenceManifest(...).valid=true`
3. Export summary:
   - Confirm checksum/signature and artifact path list.
4. Review retention:
   - Simulate future timestamp and confirm pack purges after retention window.

## Failure Path Walkthrough
Session: `session-failure`

1. Mark lifecycle failure (`markWorkspaceFailed`).
2. Confirm evidence pack exists with:
   - `teardownOutcome=failed`
   - `failureReason` populated
3. Verify manifest integrity remains valid.

## Operational Notes
- Treat exported checksums/signatures as immutable audit material.
- Attach export payloads to issue comments when proving teardown compliance.
- If an evidence pack is missing, check retention and session ID correctness first.
