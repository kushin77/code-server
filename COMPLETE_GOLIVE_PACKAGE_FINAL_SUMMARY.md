## 🚨 EMERGENCY & ROLLBACK PROCEDURES

### If Deployment Fails

**Step 1:** Stop deployment script (Ctrl+C)  
**Step 2:** Check error logs (docker-compose logs)  
**Step 3:** Review pre-deployment checks (bash pre-deployment-verification-final.sh)  
**Step 4:** Address issues and retry deployment  
**Step 5:** If critical failure, execute rollback (docker-compose down)  

### If Service Goes Down Post-Deployment

**Step 1:** Verify service status (docker-compose ps [service])  
**Step 2:** View service logs (docker-compose logs [service])  
**Step 3:** Restart service (docker-compose restart [service])  
**Step 4:** Verify health (curl -k https://kushnir.cloud/api/hermes/health)  
**Step 5:** If unrecoverable, escalate to development team  

### Complete Rollback

**If critical failure post-deployment:**
```bash
docker-compose down
git checkout HEAD~1
docker-compose up -d
bash post-deployment-verification.sh
```
