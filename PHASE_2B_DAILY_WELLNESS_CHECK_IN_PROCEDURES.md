# PHASE 2B DAILY WELLNESS CHECK-IN PROCEDURES
## Operations Lead Health Monitoring Framework (May 1-21, 2026)

**Purpose:** Systematic daily health assessment of each team member to prevent burnout and sustain performance  
**Owner:** Operations Lead (primary), Project Manager (backup)  
**Frequency:** Once per shift (minimum), twice if concerning signals detected  
**Duration:** 2-3 minutes per person × 6 leads = 15-20 minutes per shift

---

## 🏥 WELLNESS CHECK-IN OVERVIEW

### Why This Matters

```
A burned-out team:
  ✗ Makes poor decisions
  ✗ Misses critical issues
  ✗ Experiences health crises
  ✗ Fails at critical moments
  ✗ Loses institutional knowledge (quits after)
  ✗ Damages team relationships

A supported, healthy team:
  ✓ Makes sharp decisions
  ✓ Catches issues early
  ✓ Sustains 24/7 operations
  ✓ Executes flawlessly
  ✓ Stays committed long-term
  ✓ Builds lasting bonds
```

### Operations Lead Role

You are responsible for:
1. **Daily observation** - Notice physical/mental state changes
2. **Active listening** - Hear what people actually say
3. **Early intervention** - Support before crisis hits
4. **Resource provision** - Connect to help when needed
5. **Escalation** - Alert leadership to concerning patterns
6. **Documentation** - Track wellness trends

## 📋 DAILY CHECK-IN PROCEDURE

### TIMING

```
Recommended during each shift:

Alpha Shift (04:00-12:00 UTC):
  Check 1: 06:00-07:00 (2 hours into shift)
  Check 2: 10:00-11:00 (7 hours into shift)

Bravo Shift (12:00-20:00 UTC):
  Check 1: 14:00-15:00 (2 hours into shift)
  Check 2: 18:00-19:00 (6 hours into shift)

Charlie Shift (20:00-04:00 UTC):
  Check 1: 22:00-23:00 (2 hours into shift)
  Check 2: 02:00-03:00 (6 hours into shift)

Total: 2 checks per shift = better coverage

If anyone shows RED flags → check IMMEDIATELY
```

### APPROACH - CASUAL, NOT CLINICAL

**What NOT to do:**
```
✗ Don't approach with clipboard (too formal)
✗ Don't ask survey questions (feels like interrogation)
✗ Don't sit down for meeting (too serious)
✗ Don't mention "wellness check" (awkward)
✗ Don't take detailed notes in front of person (invasive)
```

**What TO do:**
```
✓ Walk by workstation with genuine interest
✓ Start conversation naturally ("How's it going?")
✓ Listen more than you talk
✓ Notice what they don't say (tone, body language)
✓ Make mental notes, write down later
```

### THE 60-SECOND CHECK-IN

**For each team member, 60 seconds:**

```
STEP 1: PHYSICAL OBSERVATION (10 seconds)
As you walk up:
  □ Eyes: Alert / Tired / Bloodshot / Unfocused?
  □ Posture: Upright / Slumped / Tense?
  □ Movement: Normal / Slow / Jittery?
  □ Color: Normal / Pale / Flushed?
  □ Hands: Steady / Trembling / Tensed?

RED FLAGS in OBSERVATION:
  🚨 Glazed/bloodshot eyes
  🚨 Slumped shoulders
  🚨 Visible tremor/tension
  🚨 Very pale or flushed
  🚨 Moving slowly like exhausted
  → If RED: Do extended check (see below)

STEP 2: CONVERSATIONAL OPENING (10 seconds)
Approach casually:
  "Hey [name], how's it going?"
  "How are we doing on this phase?"
  "Anything you need from me?"

LISTEN TO:
  □ Tone of response (energetic / flat / stressed?)
  □ Speed of response (quick / slow?)
  □ Willingness to engage (talkative / brief?)
  □ Energy in voice (high / moderate / low?)

RED FLAGS in RESPONSE:
  🚨 Monotone or flat tone
  🚨 Delayed or slow response
  🚨 Very brief answer when usually chatty
  🚨 Mention of being tired/struggling
  🚨 Irritability or frustration
  → If RED: Move to extended check

STEP 3: BRIEF FOLLOW-UP (20 seconds)
If GREEN:
  "Good. Let me know if you need anything."
  [Move to next person]

If YELLOW:
  "You seem [observation]. You okay?"
  Listen to response
  "Need anything? Break? Water? Food?"
  Offer support
  
If RED:
  "Take a second. How are you really doing?"
  Listen - let them talk
  [Follow extended check procedure]

STEP 4: MENTAL NOTES (20 seconds)
After moving away, mentally note:
  □ Energy level: High / Normal / Low / Very Low
  □ Mental state: Sharp / Normal / Foggy / Very Foggy
  □ Emotional: Positive / Neutral / Stressed / Very Stressed
  □ Physical: Healthy / OK / Tired / Exhausted
  □ Support needed: None / Minor / Significant / Immediate
```

### EXTENDED CHECK-IN (If RED flags detected)

**When you notice RED flags, pause the regular routine:**

```
LOCATION: Private, away from others

APPROACH:
"I noticed [specific observation] and I'm checking in.
 How are you really doing?"

LISTEN:
Let them talk. Don't interrupt. Ask:
  "What's the hardest part right now?"
  "What would help?"
  "Have you had enough rest?"
  "Are you okay to continue?"

ASSESS:
□ Are they safe to continue? YES / NO / UNCERTAIN
□ Do they need immediate support? YES / NO
□ Should we involve supervisor? YES / NO
□ Is this a one-time issue or pattern? ONE-TIME / PATTERN

SUPPORT OPTIONS:

If exhausted:
  Offer: "Let's get you a 30-minute break NOW"
  Action: Arrange immediate relief
  Plan: 5-hour rest tonight if possible

If stressed:
  Offer: "Talk to me about what's making this hard"
  Listen: Really listen without fixing
  Validate: "That's a lot. You're handling it well"
  Action: Lighten workload if possible

If struggling mentally:
  Offer: "This is really demanding. Want to talk?"
  Listen: Without judgment
  Validate: "Your feelings make sense"
  Action: Connect to professional support (EAP, counselor) if available

If expressing inability to continue:
  Immediate: Don't push them
  Action: Call Project Manager and CTO
  Document: Record in wellness log
  Plan: Determine coverage options

DOCUMENTATION:
After conversation, write down:
  [TIME] [NAME] [ROLE] - Extended check
  Observation: [What you observed]
  Person said: [Key statement]
  Action taken: [What you did]
  Status after: [How they seemed afterward]
  Follow-up plan: [What to do/watch next]

FOLLOW-UP:
□ Check in again in 2 hours
□ Notice if things improved / stayed same / worsened
□ Escalate if: Not improving, getting worse, or person asks
```

## 🚨 RED FLAGS - IMMEDIATE ACTION REQUIRED

### Physical Red Flags

```
🚨 CRITICAL PHYSICAL SIGNS:

Chest pain or difficulty breathing:
  Action: Call emergency services immediately
  Don't debate - this is medical emergency

Severe dizziness or fainting:
  Action: Have person sit/lie down
  Call medical support
  Don't leave person alone

Tremoring or visible distress:
  Action: Move to quiet area
  Offer water
  Call supervisor or medical support
  Monitor closely

Signs of dehydration:
  Action: Offer water immediately
  Ensure regular water breaks rest of shift
  Monitor intake

Very pale, flushed, or unwell looking:
  Action: Assess if okay to continue
  Offer rest
  Consider medical assessment
```

### Mental/Emotional Red Flags

```
🚨 CONCERNING MENTAL STATE:

Person saying they "can't do this":
  Action: Take seriously, not just frustration
  Listen: "What would help?"
  Option: Reassign workload / Take break / Call supervisor

Expressing hopelessness or despair:
  Action: Don't minimize
  Say: "This matters. Let's get support"
  Contact: Immediately call supervisor or EAP
  Escalate: Do not leave person alone

Expressing suicidal thoughts:
  Action: Take immediately seriously
  Call: Emergency services or suicide hotline
  Stay: Don't leave person alone
  Tell: Supervisor and medical professional

Signs of panic or extreme anxiety:
  Action: Get to quiet area
  Breathing: "Let's do 5 slow breaths together"
  Option: Professional support / break
  Consider: Continuing in role
```

### Performance/Behavioral Red Flags

```
🚨 CONCERNING PERFORMANCE CHANGES:

Person making poor decisions/mistakes:
  Action: Check if fatigue related
  Offer: "How much sleep did you get?"
  Option: Reassign to less critical tasks / take break
  Monitor: Is decision-making recovering?

Person missing things / not alert:
  Action: Check sleep hours
  Offer: Break + caffeine + hydration
  Monitor: Is alertness returning?
  Plan: Ensure adequate rest before next shift

Person uncharacteristically irritable/snappy:
  Action: Take as sign of stress, not personality
  Offer: "Sounds like you're stressed. What do you need?"
  Option: Lighten workload / take break
  Follow-up: Check in later

Person withdrawing/not communicating:
  Action: This can be sign of struggling
  Offer: One-on-one check
  Listen: What's happening?
  Option: Support options / supervisor input
```

## 🤝 SUPPORT INTERVENTIONS TOOLKIT

**When you identify a need, you have these options:**

### TIER 1: IMMEDIATE RELIEF (Can do right now)

```
Hydration Break
  Time: 5 minutes
  Action: Get water, sit down, stretch
  When: Anyone showing dehydration signs

Nutrition Break
  Time: 10-15 minutes
  Action: Eat something, have beverage
  When: Anyone hungry or low energy

Movement Break
  Time: 10 minutes
  Action: Walk, stretch, get outside
  When: Anyone sitting too long or stiff

Shift Relief / Task Reassignment
  Time: 30-60 minutes
  Action: Cover person's duties, let them rest
  When: Anyone showing strain
  Who: You or another team member

Fresh Air Break
  Time: 10 minutes
  Action: Step outside, breathe, reset
  When: Anyone stressed or overwhelmed

Quiet Time
  Time: 15-30 minutes
  Action: Go to break area, no meetings, rest
  When: Anyone experiencing stress/anxiety
```

### TIER 2: STRUCTURAL SUPPORT (Plan changes)

```
Workload Reduction
  Action: Reassign some tasks to others
  When: Anyone overloaded or exhausted
  Duration: Rest of shift or multiple shifts
  Check-in: Does this help?

Shift Modification
  Action: Start later / end earlier / different role
  When: Pattern of struggle with current schedule
  Approval: Project Manager or CTO
  Duration: Temporary adjustment

Buddy System
  Action: Pair struggling person with supportive peer
  When: Anyone feeling isolated or struggling
  Duration: Rest of deployment if needed
  Check-in: Is this helping?

Task Preference
  Action: Let person choose next task (if possible)
  When: Anyone experiencing decision fatigue
  Empowerment: Gives sense of control

Role Rotation
  Action: Switch to different area/responsibility
  When: Anyone burnt out on current role
  Duration: Few hours to full shift
  Benefit: Mental break + fresh challenge
```

### TIER 3: PROFESSIONAL SUPPORT (External resources)

```
Employee Assistance Program (EAP)
  If available: Call EAP counselor
  For: Mental health, stress, personal issues
  Free: Usually provided by employer
  Confidential: Outside chain of command

Medical Support
  If available: Contact occupational health
  For: Physical health concerns, medical assessment
  Scope: Can assess fitness to work safely

Supervisor / Manager
  When: If struggling person needs employer support
  For: Workload adjustment, schedule change, resources
  Documentation: Formal support plan if needed

Crisis Support
  Crisis hotline: Available 24/7 for mental health crisis
  Emergency services: If safety concern
  Never: Wait on this - act immediately
```
