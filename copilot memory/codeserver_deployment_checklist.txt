# Code Server Copilot Profile - Deployment Checklist

## Phase 1: Local Development & Testing (Your Machine)

### Week 1: Build & Package
- [ ] Clone repo & run `npm install`
- [ ] Compile TypeScript: `npm run compile`
- [ ] Create VSIX package: `npm run package`
- [ ] Test in Code Server locally:
  ```bash
  code-server --install-extension ./copilot-memory-github-profile-1.0.0.vsix
  ```
- [ ] Verify all commands work:
  - [ ] Ctrl+Shift+C opens chat
  - [ ] Ctrl+Shift+G scans GitHub
  - [ ] Commands all available in palette
- [ ] Test memory persistence:
  - [ ] Chat with copilot → send message
  - [ ] Stop Code Server, restart
  - [ ] Verify memory is still there (if using Redis/PostgreSQL)
  - [ ] OR verify message is in export (if in-memory)
- [ ] Test GitHub scanning:
  - [ ] Run "Copilot: Refresh GitHub Status"
  - [ ] Verify repos/issues appear in GitHub Status panel
  - [ ] Verify memory goals are imported

### Week 1: Test All Backends
- [ ] **In-Memory** (default):
  - [ ] Chat works
  - [ ] Memory survives session
  - [ ] Export/import works
  
- [ ] **Redis** (optional):
  - [ ] Install Redis locally: `brew install redis` (macOS)
  - [ ] Set `copilot-memory.memoryBackend = "redis"`
  - [ ] Verify memory syncs to Redis
  - [ ] Kill Code Server, restart, verify memory persists
  
- [ ] **PostgreSQL** (optional):
  - [ ] Create database: `createdb copilot_memory`
  - [ ] Set `copilot-memory.memoryBackend = "postgresql"`
  - [ ] Verify memory syncs to DB
  - [ ] Query DB directly: `SELECT * FROM goals;`

## Phase 5: Team/Enterprise Deployment

### Week 4+: Enable Team Sharing

**Option A: Shared Redis Backend**
- [ ] Deploy Redis to team infrastructure:
  ```bash
  docker run -d -p 6379:6379 --name copilot-redis redis:latest
  ```
- [ ] Share connection string with team:
  ```json
  {
    "copilot-memory.memoryBackend": "redis",
    "copilot-memory.redisUrl": "redis://shared-redis-host:6379"
  }
  ```
- [ ] All team members now share memory, GitHub context, decisions

**Option B: Shared PostgreSQL Backend** (Enterprise)
- [ ] Deploy PostgreSQL:
  ```bash
  docker run -d -e POSTGRES_DB=copilot_memory \
    -e POSTGRES_PASSWORD=secure -p 5432:5432 \
    --name copilot-postgres postgres:latest
  ```
- [ ] Create roles for different teams:
  ```sql
  CREATE ROLE team_a WITH LOGIN PASSWORD 'xxx';
  GRANT SELECT, INSERT ON goals TO team_a;
  ```
- [ ] Distribute connection strings by team

**Option C: Docker Compose (All-in-One)**
- [ ] Create `docker-compose.yml` (from distribution guide)
- [ ] Deploy to your infrastructure:
  ```bash
  docker-compose up -d
  ```
- [ ] Share Code Server URL with team
- [ ] All users access same instance + memory + GitHub context
- [ ] Add backup cron job:
  ```bash
  # Daily 2 AM backup
  0 2 * * * docker exec copilot-postgres pg_dump -U postgres copilot_memory > backup-$(date +%Y%m%d).sql
  ```

## When You Hit Problems

**"Code Server won't install the VSIX"**
- Check: Is Code Server version ≥4.0?
- Check: Is VSIX path correct?
- Try: `code-server --help | grep extension`

**"GitHub scan takes >10 minutes"**
- You might be hitting rate limits (5000 points/hour)
- Solution: Increase scan interval (`copilot-memory.scanSchedule = "0 0 * * *"`)
- Or split into smaller orgs if you have many repos

**"Memory not syncing across users"**
- Check: Are they using same Redis/PostgreSQL connection?
- Check: Do connection strings match exactly?
- Try: Test Redis/PostgreSQL directly: `redis-cli` or `psql`

**"Claude responses are generic/not memory-aware"**
- Check: Memory goals showing in "Memory State" panel?
- Check: Run "Show Memory State" — is data there?
- Try: Clear memory & reimport from GitHub
