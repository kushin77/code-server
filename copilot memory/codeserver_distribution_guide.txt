# Distribution Guide: Sharing Your Copilot Profile

> **How to package, publish, and share your self-cleaning copilot extension with other Code Server users.**

---

## 1. GitHub Setup (Primary Distribution)

### Step 1.1: Create Repository
```bash
# Create repo on GitHub: your-org/copilot-memory-profile
git clone https://github.com/your-org/copilot-memory-profile.git
cd copilot-memory-profile

# Initialize with structure:
mkdir -p src/{engines,webviews}
mkdir -p dist

# Add files:
# - package.json (from artifact 1)
# - src/extension.ts (from artifact 2)
# - README.md (from artifact 3)
# - LICENSE (MIT)
# - .github/workflows/
```

### Step 1.2: Add CI/CD Workflow (GitHub Actions)

Create `.github/workflows/build-and-release.yml`:

```yaml
name: Build & Release

on:
  push:
    tags:
      - "v*"

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: "18"
      
      - run: npm install
      - run: npm run compile
      - run: npm run package
      
      - name: Create Release
        uses: softprops/action-gh-release@v1
        with:
          files: "*.vsix"
          draft: false
          prerelease: false
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### Step 1.3: Release Process
```bash
# When ready to release:
npm version patch  # Bumps version in package.json
git push origin main --follow-tags

# GitHub Actions automatically:
# 1. Builds the extension
# 2. Packages as .vsix
# 3. Creates GitHub Release with VSIX download
```

## 2. Code Server Marketplace (Official Registry)

### Step 2.1: Register for Marketplace

1. Go to [registry.coder.com](https://registry.coder.com)
2. Sign in with GitHub
3. Click **"Publish Extension"**
4. Fill in metadata:
   - **ID**: `copilot-memory-github-profile`
   - **Name**: `Self-Cleaning Copilot with GitHub Memory`
   - **Description**: "Enterprise copilot with persistent memory, deduplication, and GitHub awareness"
   - **Repository URL**: `https://github.com/your-org/copilot-memory-profile`
   - **License**: MIT
   - **Categories**: `[Other, AI]`
   - **Keywords**: `copilot, memory, github, ai, code-server`

### Step 2.2: Add Marketplace Metadata to `package.json`

```json
{
  "publisher": "your-org",
  "repository": {
    "type": "git",
    "url": "https://github.com/your-org/copilot-memory-profile"
  },
  "bugs": {
    "url": "https://github.com/your-org/copilot-memory-profile/issues"
  },
  "homepage": "https://github.com/your-org/copilot-memory-profile",
  "icon": "icon.png",
  "keywords": [
    "copilot",
    "ai",
    "memory",
    "github",
    "code-server",
    "claude",
    "deduplication"
  ],
  "categories": ["Other", "AI"]
}
```

### Step 2.3: Upload to Marketplace

```bash
# Install marketplace CLI
npm install -g @coder/code-server-marketplace-cli

# Authenticate
coder-marketplace login --github-token $GITHUB_TOKEN

# Publish version
coder-marketplace publish \
  --path ./copilot-memory-github-profile-1.0.0.vsix \
  --version 1.0.0

# Check status
coder-marketplace info copilot-memory-github-profile
```

## 3. Direct Distribution (Self-Hosted Option)

### Option A: GitHub Releases
Users can install directly from GitHub releases:
```bash
# In Code Server, paste this in Extensions > Install from VSIX:
https://github.com/your-org/copilot-memory-profile/releases/download/v1.0.0/copilot-memory-github-profile-1.0.0.vsix
```

### Option B: Self-Hosted Marketplace
If you run your own Code Server registry:

```bash
# 1. Setup extension registry (HTTP server)
npm install -g serve
serve ./dist

# 2. Point Code Server to your registry
# Settings > extensions.marketplace = "http://your-registry.com"

# 3. Users can install from your marketplace
```

### Option C: NPM Registry (For Developers)
Publish to npm for programmatic installation:

```bash
# Update package.json
npm version patch
npm publish

# Users can install:
npm install -g @your-org/copilot-memory-github-profile
```

## 4. Docker Distribution (Team/Enterprise)

### Step 4.1: Create Dockerfile

```dockerfile
FROM codercom/code-server:latest

# Install Node dependencies
RUN apt-get update && apt-get install -y \
    git \
    python3 \
    build-essential

# Copy extension
COPY copilot-memory-github-profile-*.vsix /tmp/

# Pre-install extension
RUN code-server --install-extension /tmp/copilot-memory-github-profile-*.vsix

# Expose port
EXPOSE 8080

CMD ["code-server"]
```

### Step 4.2: Docker Compose (Team Setup)

```yaml
version: "3.8"
services:
  code-server:
    image: your-org/code-server-with-copilot:latest
    ports:
      - "8080:8080"
    volumes:
      - code-data:/home/coder/.local
      - code-projects:/home/coder/project
    environment:
      - PASSWORD=your-secure-password
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - GITHUB_TOKEN=${GITHUB_TOKEN}

  redis:
    image: redis:7
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data

volumes:
  code-data:
  code-projects:
  redis-data:
```

Deploy for entire team:
```bash
docker-compose up -d
# All team members access: http://localhost:8080
# All share same Redis backend for memory
```

## 6. Version & Update Management

### Step 6.1: Semantic Versioning

```bash
# Patch (bugfix)
npm version patch  # 1.0.0 → 1.0.1

# Minor (feature)
npm version minor  # 1.0.0 → 1.1.0

# Major (breaking)
npm version major  # 1.0.0 → 2.0.0
```

### Step 6.2: Changelog Format

Create `CHANGELOG.md`:

```markdown

- Support for PostgreSQL backend (team collaboration)
- Memory export/import command
- GitHub PR blocking detection
- Keyboard shortcut Ctrl+Shift+G for GitHub scan

- Memory corruption on concurrent updates

- Improved dedup threshold from 0.80 → 0.85
- Updated Claude model to Sonnet 4.1

## [1.0.0] - 2026-04-20

### Added
- Initial release
- Memory engine with deduplication
- GitHub scanning integration
- Code Server activity bar views
```

## 10. Long-Term Maintenance

### Release Schedule
- **Minor releases** (features): Monthly
- **Patch releases** (bugfixes): As needed
- **Major releases** (breaking): Quarterly

### Testing Before Release
```bash
npm run test
npm run lint
npm run build

# Test in real Code Server
code-server --install-extension ./dist/copilot-memory-github-profile-*.vsix

# Verify: chat works, GitHub scan works, memory persists
```

### Deprecation Policy
Document breaking changes in advance:
```markdown
## Deprecation Notice

As of v1.2.0, the `memory` backend is deprecated.
Please migrate to `redis` or `postgresql`.

Recommended timeline: Update before v2.0.0 (Q3 2026).
Migration guide: [link to docs]
```
