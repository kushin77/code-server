Portal Overview

The portal is the authenticated front door for Kushnir Cloud. It keeps the IDE separate from the landing page while sharing the same _oauth2_proxy session cookie across the entire domain.

  • Portal routing is served from Caddy and protected by oauth2-proxy session validation.
  • The IDE lives on ide.kushnir.cloud and inherits the same session cookie.
  • API and docs endpoints remain on dedicated subdomains for clear operational boundaries.
