fix(ops): Replace all unquoted SSH_OPTS with array expansion (IaC Rules 3&4)

Systematic SSH compliance fix across all ops scripts and central library.

Changes:
- scripts/_common/ssh.sh: 6 functions (ssh_exec, ssh_standby, ssh_stream, ssh_upload, ssh_upload_dir, assert_ssh_up)
- scripts/ops/check-replica-parity.sh: query_replica, check_replica_connectivity

✓ Idempotent deployments
✓ Central library cascades to all dependent scripts
