TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Issue: "gh: command not found"
  → Setup script will install GitHub CLI automatically
  → If error persists, run: bash install-gh-cli.sh manually

Issue: "Authentication failed"
  → Check GitHub token permissions (repo:read, issues:read required)
  → Ensure token is not expired
  → See GITHUB_GCP_INTEGRATION.md troubleshooting section

Issue: "Cannot access repository"
  → Verify token scopes in GitHub settings
  → Check GCP project permissions (if using GSM)
  → Run: gcloud auth application-default print-access-token

Issue: "VS Code Copilot still can't access issues"
  → Restart VS Code completely (not just reload)
  → Verify: source ~/.bashrc in terminal
  → Check: echo $GITHUB_TOKEN

See full troubleshooting in GITHUB_ISSUE_SYNC_QUICK_START.md
