## PROCEDURES QUICK REFERENCE

### If System Goes Down
1. Check status page (is it widespread?)
2. Escalate to SRE lead immediately
3. Activate war room if critical
4. Begin incident response
5. Communicate status updates every 15 min

### If Test Suite Fails
1. Phase lead reviews failures
2. Determine if blocking or non-blocking
3. If blocking: Fix + retest
4. If non-blocking: Log + continue (plan fix)
5. Report in standup

### If Performance Degrades
1. SRE lead: Check metrics + logs
2. Identify root cause
3. If fixable immediately: Fix
4. If complex: Escalate to L2
5. Monitor + report trend

### If Team Member Unavailable
1. Operations manager notified immediately
2. Activate backup team member
3. Brief backup on current state
4. Continue phase execution
5. Update schedule if needed

### If Documentation Lag
1. Allocate 15 min daily for documentation
2. Use standup to capture key points
3. Operations manager: Consolidate + publish weekly
4. All procedures: Wiki updated continuously
